OTT retention uplift

SASRec-style transformer on watch histories, then T- and X-Learner uplift models, scored against a known ground truth.

Read this first. The data is simulated, and the numbers on this page were precomputed by the pipeline in the repository and saved to data.json. No model runs in your browser and no LLM is used. "True effect" is known only because the data is simulated.

Overview

Who should get the intervention?

Contact the top share of held-out users, ranked by predicted uplift. The chart shows the expected number of extra retained users, using each user's true effect from the simulation.

Ranking quality by decile

Held-out users sorted by predicted uplift and split in ten groups. Bars show the mean true effect in each group. A good ranking falls from left to right.

Simulated segments

The simulation assigns each user a hidden segment. It drives both behaviour and how much the intervention helps. The models never see the segment.

Embedding map

t-SNE of the 128-dimensional user embeddings. Colour is the hidden segment. Hover a point for details.

Held-out users

Sorted by X-Learner predicted uplift, highest first.

Limits

  • All data is simulated. This shows that the method recovers a known effect, not how real viewers behave.
  • Treatment was randomised, so no propensity model is needed. Observational data would need one.
